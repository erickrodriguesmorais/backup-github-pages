Política de Privacidade

Última atualização: 28 de outubro de 2026

1. Finalidade

O Backup GitHub é uma ferramenta pessoal destinada a criar cópias de segurança de repositórios do GitHub e armazená-las no Google Drive do proprietário.

2. Dados acessados

A ferramenta pode acessar os arquivos dos repositórios selecionados no GitHub e os arquivos do Google Drive necessários para realizar os backups.

3. Uso e armazenamento

Os arquivos são utilizados exclusivamente para a finalidade de backup e armazenados na conta pessoal do Google Drive do proprietário. A ferramenta não oferece serviços de backup a terceiros.

4. Compartilhamento

A ferramenta não vende nem compartilha intencionalmente os dados acessados com terceiros. Os serviços Google e GitHub processam dados conforme suas próprias políticas e condições.

5. Segurança e retenção

O proprietário é responsável por proteger as credenciais de acesso e configurar a retenção dos backups. As cópias poderão ser excluídas conforme a política de retenção configurada.

6. Contato

Para questões sobre esta política, entre em contato com o proprietário do aplicativo pelo e-mail associado à conta de suporte do aplicativo.
